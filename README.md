# ekt.kz — AI-консультант

Прототип для HACKALEM AI / кейса «ИИ-ассистент-консультант и помощник для сайта ekt.kz».

## Что умеет MVP

- ищет товар по артикулу или названию;
- показывает цену, остаток и технические характеристики;
- при нулевом остатке предлагает объяснимый аналог;
- отвечает на вопросы об условиях покупки;
- не меняет корзину без фразы «Да, добавь»;
- ограничивает количество доступным остатком и показывает ссылку на корзину;
- адаптирован под мобильный экран.

## Запуск

Зависимости не нужны. Откройте `index.html` в браузере или запустите любой статический web-сервер в корне проекта.

## Архитектура

`index.html` — интерфейс чата и корзина, `app.js` — сценарии, проверка подтверждения и правила каталога, `styles.css` — адаптивная вёрстка.

В демо применена репрезентативная выборка реального API-каталога ekt.kz: артикул, название, цена, остаток и характеристики. Учётные данные API не хранятся в репозитории. В production фронтенд обращается к безопасному серверному адаптеру каталога, а не к API напрямую; сервер валидирует остаток, сессию и явное подтверждение перед операцией корзины.

## Демонстрация

1. Напишите: `Есть ли 027228?`.
2. Нажмите «Выбрать» или спросите добавить товар.
3. Убедитесь, что корзина не изменилась.
4. Напишите: `Да, добавь`.
5. Откройте ссылку на корзину.
