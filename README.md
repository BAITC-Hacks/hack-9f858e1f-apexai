# ekt.kz — консультант и корзина прототипа

Прототип команды ApexAI для HackAlem AI: поиск электротехники, характеристики, объяснимые кандидаты на замену и добавление в корзину только после подтверждения.

## Запуск

Python 3.10+; внешние Python/JS зависимости для этой версии не нужны.

```bash
cp .env.example .env
# Заполните EKT_USER и EKT_PASSWORD из документа партнёра.
# Для ответов модели добавьте OPENAI_API_KEY. Ключ не отправлять в чат и не коммитить.
python3 server.py
```

Ключ можно ввести без отображения в терминале командой `python3 setup_key.py`, затем перезапустить сервер.

Открыть http://127.0.0.1:8766. `HOST` по умолчанию 127.0.0.1, `PORT` — 8766.

Для автономного показа: `EKT_MODE=demo python3 server.py`.
В режиме `auto` ошибка API включает **явно обозначенный демонстрационный каталог**. `EKT_MODE=live` запрещает fallback. Важно: после смены `.env` сервер нужно перезапустить.

## Что реализовано

- Поиск по артикулу, названию и параметрам; запрос `DRX250 125А` не подменяется товаром на 160А.
- Карточки: цена, остаток, описание, ссылка на товар и сертификат, если API предоставил безопасную ссылку ekt.kz. Неизвестные цена/остаток отображаются как неизвестные и блокируют добавление.
- При нулевом остатке — кандидаты той же группы с совпадающими техническими параметрами и объяснением. Размеры, монтаж и совместимость требуют проверки.
- Отдельная подтверждаемая операция корзины: предложение на 5 минут, отмена, повторная проверка цены и остатка, защита от повторного подтверждения, ограничение **суммарного** количества.
- SQLite хранит корзины раздельных сессий; обновление страницы и перезапуск сервера не очищают корзину. После добавления ссылка `/basket#cart` открывает её актуальное состояние.
- Удаление позиции явной кнопкой, итоговая сумма, выгрузка списка в CSV.
- OpenAI Responses API: серверный ключ, контекст последних 6 обменов, structured output, ответы по найденным карточкам и переформулировка поиска. Модель задаётся `OPENAI_MODEL`, по умолчанию `gpt-4.1-mini`. `store:false`. При отсутствии ключа/ошибке модели остаётся детерминированный поиск, UI сообщает об этом.
- Интерфейс RU/KZ, адаптивная вёрстка. Полная локализация служебных ответов сервера на казахский пока не завершена.
- Сообщения и названия вставляются через `textContent`, а не HTML. Ключи и база не доступны через HTTP; cookie HttpOnly/SameSite, проверка Origin, CSP, ограничение размера запроса.

## Источники данных

Документ партнёра предоставляет Basic Auth и только read-only endpoints:

- `https://ekt.kz/api/products`
- `https://ekt.kz/api/products?page=2` и следующие страницы
- `https://ekt.kz/api/products/detail?id=515291`

`catalog.py` загружает страницы до конца/повторения/100 страниц, отражает полноту загрузки в статусе, перепроверяет карточку при подтверждении. Неизвестная схема или сетевой сбой не превращаются в нулевую цену или выдуманный остаток. 23 сентября 2026 после первоначальных таймаутов успешно проверены реальные список и карточка товара 515291: цена 64 920 ₸, quantity=23, stores с остатками по складам. Загружены первые 100 страниц (2000 товаров); это часть каталога. В списке нет остатков: карточка догружается перед показом наличия, подбором аналога и операцией корзины. Минимальная кратность берётся из properties.KRATNOST_MIN.

`data/demo.json` — четыре **демонстрационные** позиции, перенесённые из исходного прототипа; не актуальные цены/остатки магазина. `data/demo-policy.json` — отдельно помеченные синтетические условия покупки. Раздел 6 задания разрешает синтетические данные для прототипа. В live-режиме условия ekt.kz не выдумываются: партнёр должен предоставить подтверждённую политику оплаты/доставки/минимальной партии.

## Архитектура

Браузер (`index.html`, `app.js`, `styles.css`) → Python HTTP API (`server.py`) → EKT adapter (`catalog.py`) / OpenAI Responses API. SQLite в `.runtime/cart.sqlite3` хранит корзины, ожидающие подтверждения предложения и ограниченный контекст. Корзину меняет только код сервера, модель доступа к записи не имеет.

Секреты — локальная `.env` или переменные окружения. `.env` и `.runtime/` исключены из Git. Не использовать `python -m http.server` в корне проекта: запускайте только `server.py`, который отдаёт ограниченный список публичных файлов.

Документация OpenAI: https://developers.openai.com/api/reference/cli/resources/responses/methods/create

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Тесты покрывают поиск по параметрам, аналоги, отмену/смену запроса, накопленный остаток, дробные и отрицательные количества, истечение предложения, изменение цены/остатка, повтор подтверждения, перезапуск хранилища, изоляцию сессий, пагинацию, неизвестные поля, отказ API, контракт запроса OpenAI, закрытые серверные файлы и Origin.

Сценарий показа в деморежиме:

1. «Есть ли 027228?» → карточка: 23 шт., 64 920 ₸.
2. «Подбери аналог LED STARK 30W» → исходный товар отсутствует, предложен светильник 30W/2400Lm/4000K/IP20; автоматический выключатель не предлагается.
3. «Какие условия доставки и оплаты?» → явно помеченные демонстрационные условия.
4. «Добавь 23 шт 027228» → до подтверждения корзина пуста.
5. «Да, добавь» → 23 шт.; ссылка открывает ту же корзину. Обновить страницу — позиции сохраняются.
6. «Добавь 1 шт 027228» → отказ: суммарное количество превысит 23.
7. Новый запрос или «Отмена» не подтверждают старое предложение.

## Границы версии и интеграция

Это рабочая **корзина прототипа**, не корзина производственного ekt.kz. Партнёр не предоставил write API, механизм авторизации корзины или контракт checkout. Ссылка на внешний ekt.kz не переносит товары и не создаёт заказ. CSV позволяет передать список вручную. Для внедрения нужен серверный адаптер к официальному API корзины, с сохранением явного подтверждения и проверок остатка.

23 сентября 2026 проверен настоящий вызов OpenAI Responses API с локальным ключом, затем сквозной запрос через `/api/chat` на работающем сервере: «Характеристики 027228». Модель вернула описание Legrand DRX250 MT, 3 полюса, 160 А, 18 кА, 400 В AC по реальной карточке EKT. Проверка выполнена отдельно от 16 автоматических тестов с имитацией внешних API. Для запуска на другом компьютере нужен собственный `OPENAI_API_KEY`; ключи и локальная база в репозиторий не входят.

Можно прикрепить до пяти файлов PDF, Word, Excel или JPEG размером до 6 МБ каждый. Они сохраняются только в локальной `.runtime/` и не выдаются HTTP-сервером; для PDF/DOCX/XLSX доступен небольшой ознакомительный фрагмент, JPEG принимается без OCR. Не загружайте платёжные данные. Поиск без LLM консервативный; для свободных формулировок требуется ключ. Нет бронирования складского остатка, оплаты или создания заказа. База хранит локальный контекст, без аккаунтов и синхронизации устройств. SQLite рассчитана на один процесс; текущая блокировка сериализует запросы. HTTP-сервер предназначен для локального хакатонного показа. Перед публичным размещением нужны production-сервер, HTTPS/Secure cookies, лимиты запросов, сроки удаления сессий, мониторинг и подтверждённые интеграционные контракты.
